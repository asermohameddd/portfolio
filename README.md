* **HTML:** Used to build the structure and content of the portfolio.

## AI Assistance
AI was part of my development process while building this portfolio. I used AI mainly as a development assistant, especially when working with JavaScript. 

A significant part of the JavaScript was developed with the help of AI. I used it to help me write and understand logic, work on interactive features, debug problems, improve existing code, and find different ways to implement features. I also used AI to help with some simple HTML and CSS tasks, such as small changes to the structure, basic styling, fixing minor issues, and getting ideas for responsive behavior.

I did not use AI simply to generate the entire project and leave it as it was. I worked with the generated code, tested it, changed it when needed, and integrated it into the project. For me, AI is another tool in the development process. I use it to learn, experiment, solve problems, and move faster while still working on understanding what I am building.
